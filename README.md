# 💪 FitLog — Your Personal Workout Tracker

FitLog is a modern, responsive workout application that helps users explore exercises, view workout details, and organize their fitness routines. It provides a simple and interactive interface for managing workout plans and saving exercises for later.

## 🚀 Technologies Used

* **Next.js 16** — React framework for building the application.
* **React** — Building interactive user interfaces.
* **TypeScript** — Adding type safety to the code.
* **Tailwind CSS** — Styling responsive layouts and components.
* **DaisyUI** — Providing UI components, including loading spinners.
* **React Icons** — Adding icons throughout the application.
* **React Toastify** — Displaying toast notifications.
* **REST API** — Fetching workout data and individual workout details.

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse a collection of exercises with images, muscle groups, difficulty levels, equipment, duration, calories burned, ratings, sets, and repetitions.

### 2. 📋 Workout Details

View detailed information about individual exercises, including descriptions, equipment, difficulty, sets, repetitions, and step-by-step instructions.

### 3. ✅ Personal Workout Plan

Add exercises to your daily workout plan, mark workouts as completed, undo completion, and remove exercises when needed.

### 4. 🔖 Save for Later

Save exercises for future workouts and access them through the saved workouts section.

### 5. ⚡ Interactive User Experience

Enjoy responsive layouts, DaisyUI loading spinners, toast notifications, API error handling, and a custom 404 page for invalid routes.

## 🛠️ Getting Started

### Prerequisites

* Node.js
* npm
* Git

### Installation

1. Clone the repository:


   git clone YOUR_GITHUB_REPOSITORY_URL


2. Navigate to the project directory:

  
   cd YOUR_PROJECT_FOLDER


3. Install dependencies:


   npm install


4. Start the development server:

 
   npm run dev
   

5. Open the application in your browser:

 
   http://localhost:3000
